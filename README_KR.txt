Optimization Analysis Suite

실행 방법
1. 압축을 해제합니다.
2. index.html을 실행하면 메인 페이지가 열립니다.
3. 메인 페이지에서 4개 분석 도구로 바로 이동할 수 있습니다.

파일 구성
- index.html : 메인 랜딩 페이지
- excel.html : 01 엑셀 변환
- convergence.html : 02 Hypervolume 수렴도 확인
- distribution.html : 03 분포도 / Scatter Plot
- correlation.html : 04 상관관계 / Heatmap
- assets/common.css : 공통 디자인 및 고딕 계열 폰트 설정

외부 배포
폴더 전체를 Netlify, Vercel, GitHub Pages 등의 정적 호스팅에 업로드하십시오. 시작 파일은 index.html입니다.
